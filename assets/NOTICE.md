# Third-party assets

## material-symbols-rounded.codepoints

Icon name → codepoint list for the Material Symbols Rounded variable font, used to
populate the entity icon picker with the full catalog.

- Source: https://github.com/google/material-design-icons (`variablefont/MaterialSymbolsRounded[FILL,GRAD,opsz,wght].codepoints`)
- Copyright: Google LLC
- License: Apache License 2.0 (https://www.apache.org/licenses/LICENSE-2.0)

Only the icon names are used (to list selectable icons); glyphs are rendered by the
Material Symbols font already shipped with DankMaterialShell.
